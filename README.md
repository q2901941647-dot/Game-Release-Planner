# Game Release Planner

游戏内容排期与 AIGC 资产管理工具 

## 这个工具解决什么问题

游戏内容运营团队常年面对两个痛点：

1. **多版本并行排期容易打架**：一款游戏的版本更新往往横跨预热、爆发、长尾三个内容节奏，多款产品同时在跑时，团队很难一眼看清"这周谁该发什么"。
2. **AIGC 素材复用率低**：用 AI 生成的角色定妆图、概念视频往往一次性使用后就"沉没"，Prompt / Seed / CFG / LUT 等生产参数没有沉淀，导致下次做类似内容要从零开始抽卡。

Game Release Planner 把"版本节奏甘特图 + 任务看板 + AIGC 资产库 + 数据洞察"整合到一个轻量网页工具里，作为求职作品集展示信息架构设计与前端工程能力。

## 功能一览

|模块|说明|
|-|-|
|节奏总览|按游戏展示预热 / 爆发 / 长尾三阶段的甘特时间轴，标注今日进度线|
|任务看板|待启动 / 制作中 / 已排期 / 已发布 四列看板，支持拖拽跨列改状态、按游戏或渠道筛选、按标题搜索|
|任务详情|点击任意任务卡片查看绑定的模型、Seed、CFG、LUT 等 AIGC 生产参数，可直接更新状态或删除|
|新建任务|表单校验（标题必填）+ 即时写入看板|
|AIGC 资产库|素材元数据表格，支持按名称 / 模型 / 复用率排序，按渠道筛选|
|数据洞察|Chart.js 驱动的柱状图（各产品任务分布）、环形图（渠道占比）、素材复用率排行榜|
|导出|任务看板与资产库均可一键导出为 CSV|
|主题切换|支持浅色 / 深色手动切换，默认跟随系统 `prefers-color-scheme`|
|数据持久化|使用 `localStorage` 保存本地新增/修改的任务，刷新页面不丢失|

## 技术栈

* 纯原生 **HTML / CSS / JavaScript**，无构建步骤，双击 `index.html` 即可运行
* [Chart.js](https://www.chartjs.org/)（经 cdnjs 引入）用于数据洞察图表
* `localStorage` 做轻量本地持久化，不依赖后端
* CSS 自定义属性（CSS Variables）驱动主题系统，一套变量同时支撑浅色 / 深色两套配色

## 本地运行

无需安装依赖，两种方式均可：

1. 直接双击 `index.html` 用浏览器打开；
2. 或在项目根目录起一个静态服务器（推荐，避免部分浏览器对本地文件的安全限制）：

```bash
   cd game-release-planner
   python3 -m http.server 8080
   # 然后浏览器访问 http://localhost:8080
   ```

## 数据说明

`js/app.js` 顶部的 `DEFAULT\_TASKS`、`ASSETS`、`GAMES`、`PHASES` 均为演示数据，替换成真实排期表即可直接复用整套交互逻辑；若接入真实后端，只需把 `loadTasks` / `saveTasks` 两个函数换成对接接口的请求即可，其余渲染与交互代码不用改动。
